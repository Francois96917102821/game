# План: текстовая сюжетная игра в браузере

## Цель
Интерактивная текстовая история с выбором вариантов, несколькими концовками, звуком и картинками. Работает в браузере, удобна на телефоне, ставится как PWA.

## Решения
- Жанр: постапокалипсис + sci-fi
- Язык: русский
- Длительность: 30–60 минут
- Картинки: тёмные атмосферные иллюстрации с лёгким шумом и туманом
- Анимации: заставка при входе (логотип, глитч, дым/пыль, мерцание), плавная смена сцен, эффект печати текста, лёгкая тряска и мерцание в напряжённых моментах, частицы (пепел, искры). Всё на CSS/Canvas, без тяжёлых библиотек.

- Сюжет: «Вирус из лаборатории». Герой — бывший сотрудник корпорации, выпустившей вирус зомби. В его голове данные об антидоте. За ним охотятся и зомби, и бывшие коллеги.
- Предварительные концовки: спасти мир, продать формулу, героическая смерть

## Ещё нужно решить
- Имя героя, место действия, ключевые персонажи, развилки и итоговые 4–6 концовок

## Технологии
- Чистые HTML + CSS + JavaScript (ES-модули), без сборки на старте. Позже можно перейти на Vite.
- Сюжет в JSON (`story/*.json`), движок отдельно от контента.
- Хранение: `localStorage` (сохранения, настройки, открытые концовки).
- Хостинг: GitHub Pages (бесплатно, работает на телефоне).
- PWA: `manifest.json` + service worker (офлайн, иконка на экране).

## Структура
```
index.html
css/        стили (mobile-first)
js/         engine.js, ui.js, audio.js, save.js
story/      сцены в JSON
assets/     images/, audio/
```

## Модель сюжета
Сцена: `id`, `text`, `image`, `music`, `sfx`, `choices[]`.
Выбор: `text`, `next`, `condition` (условие), `effects` (изменение переменных).
Состояние: переменные (отношения, предметы, флаги), история, текущая сцена.
Концовки: сцены с `ending: true`, названием и описанием; список открытых концовок хранится в сохранении.

## Этапы
1. **Концепция**: жанр, герой, схема сюжета (граф сцен), список концовок (3–6).
2. **Движок**: загрузка JSON, показ сцены, выбор, переменные и условия.
3. **UI**: mobile-first, крупные кнопки, эффект печати текста, тёмная тема, меню, настройки.
4. **Сохранения**: автосохранение, продолжить, новая игра, галерея концовок.
5. **Контент**: написание сюжета и веток, проверка графа (нет тупиков и недостижимых сцен).
6. **Картинки**: фоны сцен, оптимизация (WebP, ленивая загрузка).
7. **Звук**: фоновая музыка, эффекты, кнопка mute, запуск только после первого касания (правило мобильных браузеров).
8. **PWA и публикация**: офлайн, иконки, GitHub Pages.
9. **Тестирование**: телефоны (iOS Safari, Android Chrome), все концовки, производительность.

## Критерии готовности
- Проходится целиком на телефоне без горизонтального скролла.
- Не менее 3 разных концовок, прогресс сохраняется.
- Звук и картинки включаются и выключаются, игра работает офлайн.
