# Нулевой пациент

Текстовая сюжетная игра для браузера: постапокалипсис + sci-fi, зомби, выборы и несколько концовок. Работает в телефоне.

Вы — бывший сотрудник корпорации, выпустившей вирус зомби. В вашей голове данные об антидоте, и за вами охотятся и зомби, и бывшие коллеги.

## Как поиграть
Откройте `index.html` в браузере (или через GitHub Pages, если включены).

## Структура
- `index.html`, `css/`, `js/` — движок и интерфейс
- `js/story.js` — сюжет и сцены
- `assets/` — картинки и звук (добавляются по мере разработки)
- `PLAN.md`, `STORY.md`, `SCENES.md` — план разработки, сюжетная основа и карта сцен
