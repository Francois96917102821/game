# Колодец шёпота

Небольшое браузерное приключение без сборки и сторонних игровых зависимостей.
**Играть:** https://francois96917102821.github.io/game/

Откройте `index.html` в современном браузере на компьютере или телефоне. Выбери один из шести классов — воина, следопыта, мага, плута, паладина или берсерка. На 3-м уровне выбери один из трёх подклассов своего класса; выбранная специализация автоматически усиливается на 6-м и 9-м уровнях. Исследуй пять залов, сражайся с обитателями уникальных этажей, собирай монеты и зелья и торгуй со странствующим скелетом. Каждый этаж предлагает тематических противников, особые комнаты и собственного стража. В бою накапливай запас силы обычными ударами и защитой, чтобы применять сокрушительный удар. Победы могут принести тематическое оружие и броню, а торговец продаёт дополнительные доспехи. Экипируй найденные предметы из рюкзака, чтобы наносить больше урона и лучше защищаться. Победи стража, чтобы открыть следующий участок подземелья. Текущий забег автоматически сохраняется на устройстве: после перезагрузки страницы его можно продолжить с того же места, включая незаконченный бой. Лучший достигнутый этаж также сохраняется в локальном хранилище браузера.

Игра также автоматически публикуется на GitHub Pages при изменениях в ветке `main`. Публикация запускается вручную во вкладке Actions с помощью **Publish web game → Run workflow**.
