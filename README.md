# Колодец шёпота

Небольшое браузерное приключение без сборки и сторонних игровых зависимостей.
**Играть:** https://francois96917102821.github.io/game/

Откройте `index.html` в современном браузере на компьютере или телефоне. Исследуйте пять залов, сражайтесь с обитателями уникальных этажей, собирайте монеты и зелья и торгуйтесь со странствующим скелетом. Каждый этаж предлагает тематических противников, особые комнаты и собственного стража. Победите его, чтобы открыть следующий участок подземелья. Текущий забег автоматически сохраняется на устройстве: после перезагрузки страницы его можно продолжить с того же места, включая незаконченный бой. Лучший достигнутый этаж также сохраняется в локальном хранилище браузера.

Игра также автоматически публикуется на GitHub Pages при изменениях в ветке `main`. Публикация запускается вручную во вкладке Actions с помощью **Publish web game → Run workflow**.
